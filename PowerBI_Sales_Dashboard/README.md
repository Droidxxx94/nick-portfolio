# 📊 Power BI Sales Performance Dashboard

## 📘 Overview
This Power BI dashboard analyzes monthly sales, profit, and product category performance.  
It includes interactive slicers, KPI cards, trend charts, and a branded header bar for a clean, professional layout.

## 🎯 Key Features
- Monthly sales & profit KPIs  
- Category performance breakdown  
- Interactive slicers (Month, Category)  
- Trend line visualizations  
- Clean, branded header bar  
- Professional layout and color theme  

## 🛠 Skills Demonstrated
- Power BI Desktop  
- Data modeling  
- DAX measures  
- KPI card creation  
- Slicer configuration  
- Visual layout & design  
- Dashboard branding
